# BOR Prediction Model (병상이용률 예측 모델)

병원 **병상이용률(BOR, Bed Occupancy Rate)** 을 선형 회귀로 예측하고,
결과를 Excel 파일로 자동 생성하는 연습용 Python 프로젝트입니다.

---

## 📐 BOR 계산 공식

```
BOR (%) = (재원일수 / (병상수 × 해당 월 일수)) × 100
```

---

## 📁 프로젝트 구조

```
BOR-Prediction-model/
├── bor_model.py            # 메인 실행 스크립트
├── requirements.txt        # Python 패키지 목록
├── data/
│   └── hospital_data.csv   # 샘플 병원 데이터 (2022–2024)
└── BOR_예측모델.xlsx        # 실행 후 생성되는 Excel 결과 파일
```

---

## ⚙️ 설치 및 실행

### 1. 패키지 설치

```bash
pip install -r requirements.txt
```

### 2. 모델 실행

```bash
python bor_model.py
```

실행하면 프로젝트 루트에 **`BOR_예측모델.xlsx`** 파일이 생성됩니다.

---

## 📊 Excel 출력 구성

| 시트 | 내용 |
|------|------|
| **요약대시보드** | KPI 카드 (최근 BOR, 평균, 예측 평균, 모델 R²) 및 등급 범례 |
| **실적데이터** | 월별 병상수·재원일수·BOR 실적 테이블 |
| **모델성능** | R², MAE, RMSE 지표 및 실제 vs 예측 비교 차트 |
| **BOR예측** | 향후 12개월 예측 BOR 테이블 + 실적/예측 추이 차트 |

---

## 🏷️ BOR 등급 기준

| 범위 | 등급 | 의미 |
|------|------|------|
| 90% 이상 | 🔴 과밀 | 병상 과부하 위험 |
| 75% ~ 90% | 🟢 적정 | 정상 운영 범위 |
| 75% 미만 | 🟡 여유 | 병상 활용률 제고 필요 |

---

## 🔧 커스터마이징

`data/hospital_data.csv` 파일에 실제 병원 데이터를 입력하면
그대로 예측 모델에 반영됩니다.

| 컬럼 | 설명 |
|------|------|
| `연월` | YYYY-MM 형식 (예: 2024-01) |
| `병상수` | 해당 월 가동 병상 수 |
| `재원일수` | 해당 월 전체 환자 재원일수 합계 |
| `입원환자수` | 해당 월 입원 환자 수 |
| `외래환자수` | 해당 월 외래 환자 수 |
