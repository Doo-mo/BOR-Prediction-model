# LNG 탱크 BOR 예측 엑셀 모델

> **BOR = Boil-Off Rate (LNG 증발률, 단위: %/day)**
>
> 이 저장소는 LNG(액화천연가스) 극저온 저장 탱크의 **열전달(heat ingress) 기반 증발 가스(BOG) 계산**을 위한 설계 예측용 엑셀 모델을 자동 생성하는 Python 스크립트를 제공합니다.
> 병상이용률(Bed Occupancy Rate)이나 병원 데이터와는 전혀 관계없습니다.

---

## 빠른 시작

```bash
pip install -r requirements.txt
python generate_bor_model.py
```

실행 후 `LNG_BOR_Model.xlsx` 파일이 생성됩니다.  
엑셀을 열어 **1_입력조건** 시트의 값을 변경하면 **3_BOR계산** 시트의 BOR 결과가 수식으로 자동 갱신됩니다.

---

## 물리적 배경 (정상상태 steady-state 열전달 모델)

BOG는 외부에서 탱크 내부로 침투하는 열(Q)에 의해 LNG가 증발하는 가스입니다.

```
Q [W] = ΔT / R_total
        ΔT = 외부온도 - LNG 평균비등점
        R_total = 단열재두께 / (keff × 탱크표면적 A)

BOG 질량유량 [kg/s] = Q / (LNG 평균잠열 ΔHvap [J/kg])
BOG 일일증발량 [kg/day] = BOG유량 × 86400 × 압력보정계수
LNG 총 질량 [kg] = LNG 체적 × LNG 평균밀도
BOR [%/day] = (BOG 일일증발량 / LNG 총 질량) × 100
```

## 엑셀 파일 구성 (4개 시트)

| 시트명 | 역할 |
|--------|------|
| `1_입력조건` | 사용자 입력값 (탱크 크기, 압력, 단열재, LNG 조성 등) |
| `2_물성DB` | 단열재·LNG 성분·배관 보냉계수 데이터베이스 |
| `3_BOR계산` | VLOOKUP·PI 등 엑셀 수식 기반 BOR 자동 계산 |
| `4_계측보정` | 실측 BOG로 BOR 역산 및 예측치 비교 |

---

## 입력 인자가 BOR에 반영되는 방식

| 입력 인자 | 반영 경로 | BOR에 미치는 영향 |
|-----------|-----------|-----------------|
| **압력** | 압력보정계수 = MAX(0.8, 1 − (P−1.013)×0.05) | 압력↑ → 비등점↑ → BOG↓ → BOR↓ |
| **탱크 사이즈(내경·길이)** | 표면적 A = 2πrL + 4πr², 체적 V = πr²L + (4/3)πr³ | A↑ → Q↑ → BOR↑; V↑ → BOR% ↓ |
| **LNG 충전율** | V_LNG = V × (충전율/100) | 충전율↑ → LNG총질량↑ → BOR↓ |
| **외부 온도** | ΔT = 외부온도 − LNG평균비등점 | 온도↑ → ΔT↑ → Q↑ → BOR↑ |
| **단열재 종류** | k값 = VLOOKUP(단열재, 물성DB) | k↓ → R↑ → Q↓ → BOR↓ |
| **단열재 두께** | R = 두께 / (keff × A) | 두께↑ → R↑ → Q↓ → BOR↓ |
| **진공도** | 진공보정계수: <10 Pa → 0.7, <100 Pa → 0.85, 대기 → 1.0 | 고진공 → keff↓ → R↑ → BOR↓ |
| **배관 보냉/진공 여부** | 배관계수 = VLOOKUP(배관상태, 물성DB) | 진공배관(0.1) → 추가 열유입 최소 |
| **배관 추가 열유입 비율** | Q_pipe = Q_tank × (비율%) × 배관계수 | 비율↑ → Q_total↑ → BOR↑ |
| **LNG 조성** | 잠열·밀도·비등점 = 몰분율 가중평균 (VLOOKUP × 3성분) | 조성이 LNG 물성 전체를 결정 |
| **안정화 시간** | 보정계수: <6h→1.15 / <12h→1.05 / ≥12h→1.0 | 짧으면 실측 BOG 과대 보정 |
| **BOG 계측 시간** | 실측BOG[kg/h] = 수집량[kg] / 계측시간[h] × 보정계수 | 단위시간 환산에 사용 |

## 사용 방법

1. **환경 설정**
   ```bash
   pip install -r requirements.txt
   ```

2. **엑셀 파일 생성**
   ```bash
   python generate_bor_model.py
   ```
   → `LNG_BOR_Model.xlsx` 생성

3. **엑셀 사용**
   - `1_입력조건` 시트에서 탱크 크기, 단열재, LNG 조성 등을 입력
   - `3_BOR계산` 시트에서 ★ BOR [%/day], ★ BOG [kg/h] 결과 확인
   - `4_계측보정` 시트에서 실측 BOG량을 입력하면 예측값과 비교

---

## 모델 한계 및 주의사항

- 이 모델은 **정상상태(steady-state) 열전달 기반의 설계 예측용** 모델입니다.
- 일사량, 지면 열전도, 과도현상(transient) 등의 복잡한 현장 요인은 반영하지 않습니다.
- 예측 BOR과 실측 BOR의 오차가 10% 이상이면 입력 조건(단열재 물성, 충전율, 형상)을 재확인하세요.
- LNG 성분 물성값은 대표 문헌값이며, 실제 운전 조성에 따라 달라질 수 있습니다.
